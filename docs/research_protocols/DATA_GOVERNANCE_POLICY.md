# 数据、时间与研究治理

原始材料只可按用户授权用途留存，版权禁止归档时只留合法元数据/链接。原件与解析文件分别保存，SHA256贯通；资料不会因摘要更短而被覆盖。

Tier A、Tier B都保留各自来源；不能按优先级把另一来源悄悄覆盖。相同身份不同内容触发ConflictError并留冲突记录。实体仅用明确名称+类型或人工指定键识别，自动别名合并未实现，疑似重名需人工处理。

时间必须含偏移量；UTC入库存储并保留原始串。PIT采用严格的系统可用时间（含captured_at）；公共发布时间与本地采集时间不混淆。历史研究必须声明采用公共信息可用性还是本系统已知信息，本版仅实现更保守的后者。

人物观点必须绑定PERSON、可定位的原文Evidence、发表时间、类型、目标和周期。系统解释应独立作为hypothesis/observation，不冒充作者引语。用户报告、MOCK、机器提取都默认UNVERIFIED。无真实流沙河文章时保留空档案，不生成准确率。

RQ-OBS-01在Case中关联event/opinion/market_bar/observation。当前只证明结构与证据链；正式实验需另行预注册样本总体、benchmark、窗口、失效定义、排除规则和多重检验。失败案例与争议信息不能删。

没有账户、持仓、计划、订单、策略参数或LIVE写入路径。网络与实盘导入默认禁用；本轮不提供可误触的环境变量开关。未来采集需明确来源/端点/许可/频率授权并独立测试。
